# アウトライナーメモ

Dynalistのような無限階層アウトライナーに、Axios風「スマート構造化」と、
書き出し不要の完全自動保存・自動同期を組み合わせたメモアプリです。

- 1文字入力するたびに自動保存(IndexedDB即時保存 + Supabaseへ非同期同期)
- トグル折りたたみ・無限階層・ドラッグ&ドロップでの並べ替え
  (子を持つ行は「＞」、末端の行は「・」を自動表示。数値バッジ等は付けない文字のみの表示)
- 文字の階層(深さ)に応じて文字サイズを自動調整(第1階層=大+太字、第2階層=中、
  第3階層以降=小)。行頭アイコンは常にテキストと上下中央に整列する
- 選択した文字だけを黒/赤/青の3色から選んで文字色にできるインライン装飾
  (ライト/ダーク両方で読みやすい配色)
- 💡なぜ重要なのか / 🌐背景・これまでの流れ / 📚深掘り / 🚀今後の動き・活かし方 / 📝メモ、
  の5種の「スマート構造化」ブロック(子として1段深くならず、同じ階層に追加される。
  内部にはTabで自由に子ノードを作ったり、既存のノードをドラッグ&ドロップで
  出し入れできる。ブロック内部の文字サイズは階層に関わらず常に「小」で統一される)
- 本文中のURLは自動でクリック可能なリンクになり、クリックで新しいタブに開ける。
  「...」と入力すると自動で三点リーダー「…」に変換される
- マウスドラッグで複数の行をまとめて範囲選択でき(青くハイライト)、選択中は
  Backspace/Deleteで一括削除、Tab/Shift+Tabで一括インデント、ドラッグ&ドロップで
  まとめて移動できる。ドラッグ&ドロップは行の上下25%が前後への並べ替え、
  中央50%がその行の子として直接入れ込む「中に入れる」ゾーンになっている
- Ctrl/Cmd+Zで元に戻す、Ctrl+Y(またはCtrl/Cmd+Shift+Z)でやり直す、に対応。
  画面下部の操作バーからも「↩ 元に戻す」「↪ やり直す」ボタンで操作できる
- メモを整理する無限階層のフォルダ機能(フォルダの中にフォルダも作成可能)。
  メモ・フォルダともにドラッグ&ドロップで自由に移動できる
- サイドバーは開閉・幅のドラッグリサイズが可能。フォルダの操作は「…」またはフォルダの
  右クリックから行い、階層が深くてもフォルダ名・メモタイトルが見切れないようにしている
- Notion風の2段階Ctrl/Cmd+A(1回目=ブロック内、2回目=メモ全体を選択してコピー)と、
  改行を含むテキストの貼り付けで複数ノードに自動展開
- 全メモ横断のリアルタイム検索(マッチ箇所を黄色くハイライト、結果をクリックしてジャンプ)
- ライト/ダークモード(システム設定連動 or 手動固定)。画面中央にメモタイトルを大きく表示し、
  ウィンドウが狭いときは検索・自動保存インジケーターがアイコン1つに縮小する
- PC(キーボード)・iPad(タッチ+外付けキーボード)・スマホ(フリック入力)対応
- Supabase未設定でもIndexedDB/localStorageにフォールバックし、オフラインで書き続けられる

## セットアップ

```bash
npm install
npm run dev
```

`http://localhost:3000` を開くと、まずローカル専用モード(Supabase未接続)ですぐに使い始められます。

### Supabaseでクラウド同期を有効にする(任意)

1. [supabase.com](https://supabase.com) で無料プロジェクトを作成
2. プロジェクト設定 > API から `URL` と `anon public key` を取得
3. Authentication > Providers > **Anonymous Sign-ins** を有効化
   (ログイン画面なしで書き始められるようにするための匿名認証)
4. SQL Editor で [`supabase/schema.sql`](supabase/schema.sql) の内容を実行
   (テーブル作成・RLS設定・Realtime有効化まで一括で行われます)
5. `.env.local.example` を `.env.local` にコピーし、値を入力

```bash
cp .env.local.example .env.local
```

```
NEXT_PUBLIC_SUPABASE_URL=https://xxxxx.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=xxxxxxxxxxxxxxxx
```

6. 開発サーバーを再起動すると、以後は自動でクラウド同期されます
   (画面右上のインジケーターで保存状態を確認できます)

## キーボードショートカット(PC・iPad外付けキーボード)

| 操作 | キー |
| --- | --- |
| 新規ノード追加(カーソル位置で分割、常に同じ階層に追加) | Enter |
| ノード内で改行 | Shift + Enter |
| 削除(空ノード・全選択時) / 前のノードへ結合 | Backspace |
| インデントを下げる(子にする。スマート構造化ブロックの内部でも可) | Tab |
| インデントを上げる(親と同じ階層に戻す) | Shift + Tab |
| 折りたたみ切り替え | Cmd/Ctrl + Enter |
| ブロック内を全選択 → もう一度でメモ全体を選択 | Cmd/Ctrl + A(2回) |
| 選択解除 | Escape |
| 兄弟内で上下に移動 | Alt + ↑ / ↓ |
| 前後のノードへ移動 | ↑ / ↓(行頭・行末で) |
| スマートブロック挿入 | Cmd/Ctrl + Shift + 1〜5 |
| 元に戻す | Cmd/Ctrl + Z |
| やり直す | Cmd/Ctrl + Shift + Z、または Ctrl + Y |

マウスで複数行をドラッグすると範囲選択(青ハイライト)になり、選択中は上表のBackspace/Tab/
Shift+Tabが選択した行全体に一括適用されます。スマホ・タッチ操作時は画面下部の操作バー
(インデント上げ下げ・折りたたみ・元に戻す・やり直す)を使用します。並べ替えはマウスドラッグ・
タッチの長押しドラッグに一本化しています(行の中央にドロップすると、その行の子として
直接入れ込まれます)。行の操作ボタン(構造化挿入・文字色・削除)は、マウス操作の環境では
ホバー時のみ、タッチ操作の環境では常時表示されます。

## データモデル

`folders`(フォルダ、`parent_id`で無限階層)・`notes`(メモ単位、`folder_id`で所属フォルダを参照)・
`nodes`(アウトラインの各行、`parent_id`で無限階層)の3テーブル構成です。
`position` は浮動小数の中点挿入方式(挿入のたびに兄弟を振り直さない)。
`content`は装飾用のごく小さなホワイトリストHTML(`<span style="color">`
`<a href target rel>` `<br>`のみ、hrefはhttp(s)のみ許可)です。
`font_size`・`highlight_color`列は過去バージョンの手動フォントサイズ/蛍光ペン機能の名残で、
データ互換のためスキーマ・型には残していますが、現在のUIからは読み書きしません
(文字サイズは階層の深さから自動計算する方式に変わりました)。
詳細は [`supabase/schema.sql`](supabase/schema.sql) と [`src/types/outline.ts`](src/types/outline.ts) を参照してください。

## 既知の制約(今後の拡張候補)

- 匿名認証はブラウザ単位のセッションです。同じアカウントで複数端末に確実に同期したい場合は、
  メールログイン等の本人認証への切り替えが今後の拡張候補になります。
- 同時編集の競合解決は簡易的な最終更新優先(last-write-wins)です。
- 検索は最大30件までの表示です。
- Undo/Redoはノード構造・本文の変更を対象にした、開いているメモ単位の履歴です(メモを
  切り替えると履歴はリセットされます)。折りたたみの開閉状態は対象に含めていません。
- 文字色を選択範囲に適用すると、その瞬間のテーマの色で固定されます(後からテーマを
  切り替えても、選択適用済みの色は自動追従しません。ノード全体の既定色はテーマに追従します)。
- 1つのメモが非常に大きくなった場合のレンダリング最適化(ノード単位の粒度でのメモ化)は
  今後の改善余地です。通常のメモ運用では体感できない範囲です。
