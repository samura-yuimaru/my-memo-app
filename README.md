# OutLiner(アウトライナー)

Dynalistのような無限階層アウトライナーに、Axios風「スマート構造化」と、
書き出し不要の完全自動保存・自動同期を組み合わせたメモアプリです。

- 1文字入力するたびに自動保存(IndexedDB即時保存 + Supabaseへ非同期同期)
- トグル折りたたみ・無限階層・ドラッグ&ドロップでの並べ替え
  (子を持つ行は「＞」、末端の行は「・」を自動表示。数値バッジ等は付けない文字のみの表示)
- 文字の階層(深さ)に応じて文字サイズを自動調整(第1階層=大+太字、第2階層=中、
  第3階層以降=小)。行頭アイコンは常にテキストと上下中央に整列する
- 選択した文字だけを黒/赤/青の3色から選んで文字色にできるインライン装飾
  (ライト/ダーク両方で読みやすい配色)
- 💡なぜ重要なのか / 🌐背景・これまでの流れ / 📚深掘り / 🚀今後の動き・活かし方 / 📝メモ、
  の5種の「スマート構造化」ブロック(子として1段深くならず、同じ階層に追加される。
  内部にはTabで自由に子ノードを作ったり、既存のノードをドラッグ&ドロップで
  出し入れできる。ブロック内部の文字サイズは階層に関わらず常に「小」で統一される)
- 本文中のURLは自動でクリック可能なリンクになり、クリックで新しいタブに開ける。
  「...」と入力すると自動で三点リーダー「…」に変換される
- マウスドラッグで複数の行をまとめて範囲選択でき(青くハイライト)、選択中は
  Backspace/Deleteで一括削除、Tab/Shift+Tabで一括インデント、ドラッグ&ドロップで
  まとめて移動できる。ドラッグ&ドロップは行の上下25%が前後への並べ替え、
  中央50%がその行の子として直接入れ込む「中に入れる」ゾーンになっている
- Ctrl/Cmd+Zで元に戻す、Ctrl+Y(またはCtrl/Cmd+Shift+Z)でやり直す、に対応。
  画面下部の操作バーからも「↩ 元に戻す」「↪ やり直す」ボタンで操作できる
- メモを整理する無限階層のフォルダ機能(フォルダの中にフォルダも作成可能)。
  メモ・フォルダともにドラッグ&ドロップで自由に移動できる
- サイドバーは開閉・幅のドラッグリサイズが可能。フォルダの操作は「…」またはフォルダの
  右クリックから行い、階層が深くてもフォルダ名・メモタイトルが見切れないようにしている
- Notion風の2段階Ctrl/Cmd+A(1回目=ブロック内、2回目=メモ全体を選択してコピー)と、
  改行を含むテキストの貼り付けで複数ノードに自動展開
- 全メモ横断のリアルタイム検索(マッチ箇所を黄色くハイライト、結果をクリックしてジャンプ)
- ライト/ダークモード(システム設定連動 or 手動固定)。画面中央にメモタイトルを大きく表示し、
  ウィンドウが狭いときは検索・自動保存インジケーターがアイコン1つに縮小する
- PC(キーボード)・iPad(タッチ+外付けキーボード)・スマホ(フリック入力)対応
- Supabase未設定でもIndexedDB/localStorageにフォールバックし、オフラインで書き続けられる
- サイドバー左上のブランドヘッダー(ファビコン・ホーム画面アイコンと同一デザインの
  アプリアイコン + アプリ名で統一)
- ゴミ箱・並べ替えハンドル・「…」メニュー・スマート構造化・文字色ボタンなどの操作アイコンは、
  常時表示だと階層が読みにくくなるため、「選択中(アクティブ/網掛け)」または「ホバー中」
  (マウス・トラックパッド・Apple Pencilホバー)のときだけ表示する
- 行頭の6点アイコンだけでなく、行(メモ・フォルダ・アウトラインの各行)を長押しする
  ことでもドラッグでの階層移動ができる。長押しして指を動かさずに離すと、その場で
  メモ名・フォルダ名を変更できる(iOS標準のリンクプレビュー/コールアウトは発動しない
  よう抑止済み)
- 複数行の範囲選択(網掛け)は、ライト/ダークどちらのテーマでも同じ鮮やかな水色の背景+
  濃い文字色に固定しているため、テーマに関わらずはっきり読める
- 「≪ インデント解除」「≫ インデントを下げる」「↲ 元に戻す(Undo)」「↳ やり直す(Redo)」の
  4ボタンの操作ツールバー(OutlineToolbar)は、キーボード表示・非表示を問わず常に同一の
  コンポーネント・同一のボタン定義を描画する一元化された設計。ソフトウェアキーボード表示中は
  キーボードのすぐ上に浮遊追従し、非表示中は画面下部に固定表示される(位置が変わるだけで
  挙動やボタン構成が食い違うことはない。Undo/Redoは編集中のテキストも含めたアウトライン
  全体の操作履歴と連携する)
- 画面右上の☑マークは、Supabaseの匿名認証セッション(userId)・オンライン状態・
  ローカル未送信キューの件数・実際の書き込み完了イベントをすべて踏まえて状態を判定する。
  緑チェック「クラウド同期済み(Supabase)」・青回転「同期中/接続中」・黄色「オフライン」・
  赤「同期エラー」・グレー「端末のみに保存(Supabase未設定)」の5状態を明確に区別して表示し、
  「緑チェックなのにローカル専用・未同期の文言が出る」といった表示不整合が起きないようにしている。
  タップすると最終同期時刻(○分前 / HH:mm:ss)の確認、全データのJSON書き出し/読み込み
  (バックアップ・機種変更時の引き継ぎ)に加えて、未接続/エラー時はワンタップで
  再接続できるボタンが出る
- Supabaseへの匿名サインインは起動時・オンライン復帰時に指数バックオフ付きで自動リトライし、
  成功したら即座に未送信分の同期キューを処理する。セッションが失効した場合も
  (onAuthStateChangeで検知して)自動的に再認証をやり直す
- セキュリティ強化: 全テーブルでRLS(`auth.uid() = user_id`)による厳格な行単位の分離に加えて、
  未認証のanonロールからテーブル権限そのものを剥奪(多層防御)。JSONインポート・
  リアルタイム受信・DOM描画の各段階でHTMLサニタイズを行いXSSを防止。本番ビルドでは
  内部エラーメッセージも含めコンソールへのログ出力を行わない

## セットアップ

```bash
npm install
npm run dev
```

`http://localhost:3000` を開くと、まずローカル専用モード(Supabase未接続)ですぐに使い始められます。

### Supabaseでクラウド同期を有効にする(任意)

1. [supabase.com](https://supabase.com) で無料プロジェクトを作成
2. プロジェクト設定 > API から `URL` と `anon public key` を取得
3. Authentication > Providers > **Anonymous Sign-ins** を有効化
   (ログイン画面なしで書き始められるようにするための匿名認証)
4. SQL Editor で [`supabase/schema.sql`](supabase/schema.sql) の内容を実行
   (テーブル作成・RLS設定・Realtime有効化まで一括で行われます)
5. `.env.local.example` を `.env.local` にコピーし、値を入力

```bash
cp .env.local.example .env.local
```

```
NEXT_PUBLIC_SUPABASE_URL=https://xxxxx.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=xxxxxxxxxxxxxxxx
```

6. 開発サーバーを再起動すると、以後は自動でクラウド同期されます
   (画面右上のインジケーターで保存状態を確認できます)

## キーボードショートカット(PC・iPad外付けキーボード)

| --- | --- |
| 新規ノード追加(カーソル位置で分割、常に同じ階層に追加) | Enter |
| ノード内で改行 | Shift + Enter |
| 削除(空ノード・全選択時) / 前のノードへ結合 | Backspace |
| インデントを下げる(子にする。スマート構造化ブロックの内部でも可) | Tab |
| インデントを上げる(親と同じ階層に戻す) | Shift + Tab |
| 折りたたみ切り替え | Cmd/Ctrl + Enter |
| ブロック内を全選択 → もう一度でメモ全体を選択 | Cmd/Ctrl + A(2回) |
| 選択解除 | Escape |
| 兄弟内で上下に移動 | Alt + ↑ / ↓ |
| 前後のノードへ移動 | ↑ / ↓(行頭・行末で) |
| スマートブロック挿入 | Cmd/Ctrl + Shift + 1〜5 |
| 元に戻す | Cmd/Ctrl + Z |
| やり直す | Cmd/Ctrl + Shift + Z、または Ctrl + Y |

マウスで複数行をドラッグすると範囲選択(網掛け)になり、選択中は上表のBackspace/Tab/
Shift+Tabが選択した行全体に一括適用されます。この範囲選択はライト/ダークどちらのテーマでも
同じ鮮やかな水色の背景+濃い文字色に固定しているため、テーマに関わらずはっきり読めます。
スマホ・タッチ操作時は「≪インデント解除・≫インデント・↲元に戻す(Undo)・↳やり直す(Redo)」の
4ボタンのツールバー(OutlineToolbar)を使用します。キーボード表示の有無で見た目上の位置は
変わります(非表示中は画面下部に固定、表示中はキーボードのすぐ上に浮遊追従)が、実体は
常に同一のコンポーネント・同一のボタン定義で、挙動が食い違うことはありません
(Undo/Redoは編集中のテキストを含むアウトライン全体の操作履歴と連携します)。並べ替えは
マウスドラッグ・タッチの長押しドラッグに一本化しています(行の中央にドロップすると、
その行の子として直接入れ込まれます。行頭の6点アイコンだけでなく行全体の長押しでも
ドラッグを開始できます)。行の操作ボタン(構造化挿入・文字色・削除・並べ替えハンドル・
「…」メニュー)は、マウス操作の環境ではホバー時のみ、それ以外ではその行が選択中/
操作対象のときだけ表示されます。

## データモデル

`folders`(フォルダ、`parent_id`で無限階層)・`notes`(メモ単位、`folder_id`で所属フォルダを参照)・
`nodes`(アウトラインの各行、`parent_id`で無限階層)の3テーブル構成です。
`position` は浮動小数の中点挿入方式(挿入のたびに兄弟を振り直さない)。
`content`は装飾用のごく小さなホワイトリストHTML(`<span style="color">`
`<a href target rel>` `<br>`のみ、hrefはhttp(s)のみ許可)です。
`font_size`・`highlight_color`列は過去バージョンの手動フォントサイズ/蛍光ペン機能の名残で、
データ互換のためスキーマ・型には残していますが、現在のUIからは読み書きしません
(文字サイズは階層の深さから自動計算する方式に変わりました)。
詳細は [`supabase/schema.sql`](supabase/schema.sql) と [`src/types/outline.ts`](src/types/outline.ts) を参照してください。

## セキュリティ

- **RLS(行レベルセキュリティ)**: `folders`/`notes`/`nodes`の全テーブルで
  `auth.uid() = user_id` による厳格な行単位の分離を適用しています(匿名認証ユーザーにも
  個別のUUIDが割り当てられるため、他人のデータには一切アクセスできません)。
  さらに、未認証のanonロールからはテーブル権限そのものを剥奪し、`authenticated`
  ロール(匿名認証セッションを含む)のみに絞っています(多層防御)。
  **既存のSupabaseプロジェクトを使っている場合は、[`supabase/schema.sql`](supabase/schema.sql)
  を SQL Editor で再実行してこの権限設定を反映してください**(冪等なので何度実行しても安全です)。
- **XSS対策**: ノードの`content`はホワイトリスト方式のHTMLサニタイズ(`sanitizeHtml`)を、
  (1) 編集終了時、(2) JSONインポート時、(3) Supabase Realtimeでの受信時、(4) DOMへの
  描画直前、の4箇所すべてで通しています。JSONインポートは端末外から持ち込まれる
  信頼できない入力として扱い、`<script>`等を仕込んだ改ざんファイルを読み込んでも
  安全なタグ・属性(`span`のcolor/background-color、`br`、http(s)の`a href`)以外は
  すべて除去されます。
- **クライアント設定**: Supabaseクライアントは環境変数(URL形式・httpsであること)を
  検証してから初期化し、失敗時は例外を投げずローカル専用モードにフォールバックします。
  APIキーやセッショントークンの値そのものをconsoleへ出力する処理はコード中に一切なく、
  デバッグ用のエラーログ(Supabaseのエラーメッセージ等)も本番ビルドでは出力しません。
- **セッション**: 匿名認証セッションは`autoRefreshToken`で自動更新され、`onAuthStateChange`で
  サインアウト・失効を検知した場合は自動的に再認証(匿名サインインのやり直し)を行います。
  OAuthリダイレクトは使わないため`detectSessionInUrl`を無効化し、URL経由のセッション
  解析という攻撃面自体を塞いでいます。

## 堅牢性・パフォーマンス

- **データロス防止**: すべての変更はまずIndexedDBへ同期的に保存してからSupabaseへ非同期送信します。
  ネットワーク瞬断やSupabase側の障害でAPI呼び出しが失敗(またはfetch自体が例外を投げた)場合も、
  `safeCall`ラッパーが必ず同じ経路(dirty化 / 削除キュー登録)に載せるため、変更が黙って
  失われることはありません。オンライン復帰・再認証成功時に未送信分をまとめて自動再送します。
- **同期ステータスの厳格な判定**: 画面右上の☑が🟢「クラウド同期済み」を名乗るのは、
  (1)認証セッション確立・(2)オンライン・(3)送信中/エラーではない・(4)未送信キューが0件、
  の4条件すべてを満たした場合のみです。
- **エラーバウンダリ**: サイドバー・アウトライン本体・アプリ全体をそれぞれReact Error Boundaryで
  囲んでいます。IndexedDB/Supabaseの想定外のデータ形状で描画中に例外が起きても、
  白画面クラッシュせずその領域だけ再表示ボタン付きのフォールバックUIになります。
- **大量ノードでの描画性能**: `OutlineNode`はカスタム比較関数付きの`React.memo`でラップしており、
  ツリー全体が毎回新しいオブジェクトとして再構築されても、実際に内容が変わっていない行
  (と、その子の並びが変わっていない行)は再レンダリングされません。1000行規模のメモでも、
  1箇所を編集した際に再描画されるのは変更のあった行の祖先チェーンだけです。

## 既知の制約(今後の拡張候補)

- 匿名認証はブラウザ単位のセッションです。同じアカウントで複数端末に確実に同期したい場合は、
  メールログイン等の本人認証への切り替えが今後の拡張候補になります。
- 同時編集の競合解決は簡易的な最終更新優先(last-write-wins)です。
- 検索は最大30件までの表示です。
- Undo/Redoはノード構造・本文の変更を対象にした、開いているメモ単位の履歴です(メモを
  切り替えると履歴はリセットされます)。折りたたみの開閉状態は対象に含めていません。
- 文字色を選択範囲に適用すると、その瞬間のテーマの色で固定されます(後からテーマを
  切り替えても、選択適用済みの色は自動追従しません。ノード全体の既定色はテーマに追従します)。
- 1つのメモが非常に大きくなった場合のレンダリング最適化(ノード単位の粒度でのメモ化)は
  今後の改善余地です。通常のメモ運用では体感できない範囲です。
